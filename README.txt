SWIFT MC — LemonCloud-inspired homepage

1. Extract this ZIP.
2. Open index.html to preview.
3. Upload index.html and the complete assets folder to your static website hosting.

This version recreates the bright sky/rays, floating islands and clouds, centered Swift MC branding, and six illustrated clickable menu cards. The motion is made with CSS animations; no external video file is bundled.

Temporary URLs are in the `destinations` object at the bottom of index.html:
- News: https://example.com/swiftmc-news
- Vote: https://example.com/swiftmc-vote
- Store: https://example.com/swiftmc-store
- Rules: https://example.com/swiftmc-rules

Replace the example.com URLs whenever ready. Discord and Staff currently point to https://discord.gg/nFV8DzaTb.
The top server pill copies `swiftmc.fun`; port is 40503.
